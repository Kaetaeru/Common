# JLPT 단어 암기 PWA — 설계

작성일: 2026-10-06
구현 계획: [2026-10-06-plan.md](2026-10-06-plan.md)

## 목표

- 2026-12-06(일) 일본 현지 JLPT N1 응시 전까지 N2·N1 어휘를 간격 반복으로 익힌다.
- 안키처럼 데이터를 직접 넣는 수고 없이, 단어 목록이 앱에 내장되어 있다.
- 사용자 1명, 아이폰 1대. GitHub Pages(`https://kaetaeru.github.io/Common/jlpt-vocab/`)에 정적 파일로 배포하고 홈 화면에 추가해서 쓴다.

## 범위 밖 (YAGNI)

예문, 음성(TTS), 기기 간 동기화, 로그인, 역방향 카드(뜻→단어), 제외 단어 재점검, 요일별 분량 조절,
복습 과부하 시 신규 자동 감소, 다크모드 토글(시스템 설정을 따름).

## 기술 방식

- 빌드 없는 정적 PWA. 프레임워크·외부 의존성 없음. ES module(`<script type="module">`).
- 저장: `localStorage`. 키 앞에 `jlpt-vocab:`를 붙인다. `kaetaeru.github.io`의 다른 Common 앱과 저장소를 공유하기 때문이다.
- 오프라인: Service Worker. Common의 다른 앱(`docs/workout-timer/sw.js`)과 같은 네트워크 우선 + 캐시 대체 방식.
- 시험장(일본)과 한국은 같은 UTC+9라 시간대 처리는 필요 없다.

## 화면

### 1. 홈
- `N1까지 D-n` 표시.
- 오늘 할 일: `오늘 복습 n · 신규 n`.
- 메인 버튼 [학습 시작]. 할 일이 없으면 비활성.
- 훑어보기 미완료 시 보조 버튼 [훑어보기로 아는 단어 빼기 (340/4447)]. 훑어보기는 선택 사항이다(2026-10-07 변경).
- 오늘 신규 할당량이 60 초과면 경고.
- 진도가 있고 마지막 백업 후 7일 초과(또는 백업한 적 없음)면 백업 알림.

### 2. 훑어보기 (분류)
- 앞면에 단어(`k`)만 표시.
- [안다]: 답을 보지 않고 `known` 처리, 다음 카드.
- [모른다]: 답(읽기+뜻) 1초 표시 후 다음 카드. 학습 대상(`new`)이 된다.
- 오른쪽 스와이프 = 안다, 왼쪽 스와이프 = 모른다. [되돌리기]로 직전 1장 취소.
- 순서: `words.json` 순서. 중간 이탈 후 이어서 가능.

### 단어 순서 (2026-10-08 변경)
- `build_words.py`의 `kanji_order`가 같은 한자 단어끼리 묶는다. 단어마다 다른 단어와 공유하는 한자 중 가장 드문 것을 기준으로 묶는다(묶음 최대 11개). 묶음은 N2 단어가 든 것부터, 묶음 안은 N2 → N1.
- 진도는 단어 키 기준이라 순서가 바뀌어도 이미 배운 단어는 그대로다.
- 학습 뒷면에 같은 한자를 쓰는, `review`·`known` 상태 단어를 드문 한자부터 최대 3개 보여준다.
- 훑어보기를 나가면 오늘 신규 할당량을 다시 계산한다(새로 분류된 `new`를 반영).

### 3. 학습
- 앞면 단어 → 카드 탭 → 뒷면 읽기 + 한국어 뜻, 아래에 영어 뜻(작게).
- 가나만 있는 단어(`k === r`)는 뒷면에 읽기를 생략한다.
- 평가 버튼 3개: [모름] [애매] [앎].
- 순서: 기한 도래 복습 전부(due 오름차순) → 신규(남은 할당량만큼, `words.json` 순서). 신규에는 훑어보기 전 단어(`progress`에 키 없음)도 포함한다.
- 신규 카드(재출제 제외)에는 [이미 앎 — 학습에서 빼기] 버튼: 평가 없이 `known` 처리하고 다음 카드.
- 뒷면 [✎ 뜻 고치기]로 한국어 뜻 수정(`edits`에 저장, 빈 값이면 원래 뜻으로 복원).
- 큐가 비면 "오늘 끝" 표시, 카드를 탭하면 홈으로.

### 4. 설정·통계
- 시험일(변경 가능), 버퍼 일수(기본 7, 변경 가능). 바꾸면 오늘 할당량을 다시 계산한다.
- 전체 단어 / 훑어보기 안 함 / 제외(known) / 아직 안 배운 단어(훑어보기 전 + new) / 학습 중(review) / 오늘 신규 할당 / 마지막 백업.
- [백업 내보내기], [가져오기].

## 스케줄러 (`sched.js`)

### 날짜
- 날짜는 일 번호(정수, UTC epoch 기준 일수)로 다룬다. 하루 경계는 로컬 시간 새벽 4시.
- `dayNum(date)`: 시각에서 4시간을 뺀 로컬 날짜의 일 번호.
- `parseDay('YYYY-MM-DD')`, `isoDay(n)`: 문자열 ↔ 일 번호.

### 단어 상태
`[st, due, ivl, ease, lapses]`
- `st`: `new` | `review` | `known`. 훑어보기 전 단어는 `progress`에 키가 없다.
- `newState() = ['new', 0, 0, 2.5, 0]`, `knownState() = ['known', 0, 0, 2.5, 0]`.

### 평가 규칙 `grade(state, g, today)` (SM-2 단순화)

| g | 버튼 | 간격 | ease |
|---|---|---|---|
| 0 | 모름 | `ivl = 1` | `ease − 0.2`, `lapses + 1` |
| 1 | 애매 | `ivl = max(1, round(ivl × 1.2))` | `ease − 0.15` |
| 2 | 앎 | `ivl` 0→1, 1→3, 그 외 `round(ivl × ease)` | 변화 없음 |

- ease는 소수 둘째 자리로 반올림하고 하한 1.3.
- 모든 간격에 상한 `MAX_IVL = 14`일.
- 결과: `['review', today + ivl, ivl, ease, lapses]`.
- 세션 안 재출제: 카드의 **첫 평가만** 저장한다. 첫 평가가 모름이면 그 카드를 큐의 5장 뒤에 다시 넣고, 재출제 카드에서 모름이면 또 5장 뒤에 넣는다. 재출제 카드의 애매/앎은 저장하지 않고 넘긴다.

### 하루 신규량

```
newPerDay(remainingNew, today, exam, buffer)
  = exam - today - buffer <= 0 또는 remainingNew <= 0 ? 0
  : ceil(remainingNew / (exam - today - buffer))
```

- `buffer` 기본 7일. 마지막 7일은 복습만 한다.
- `quota(remainingNew, today, settings) = newPerDay(remainingNew + settings.newDoneToday, today, exam, buffer)` — 오늘 이미 시작한 신규를 포함해서 계산한다.
- `rollDay(settings, today, remainingNew)`: 날짜가 바뀌었으면 `today` 갱신, `newDoneToday = 0`, `quotaToday` 계산. 같은 날이면 그대로.
- `remainingNew`는 아직 안 배운 단어 수: `words.json` 단어 중 `progress`에 키가 없거나 `new`인 것.
- 오늘 남은 신규 = `min(quotaToday − newDoneToday, remainingNew)`.

### 큐 `buildQueue(keys, progress, today, newCount)`
- `review`이면서 `due <= today`인 키를 due 오름차순으로, 그 뒤에 `new` 키를 `keys` 순서로 최대 `newCount`개.

## 데이터

### 원본
- `elzup/jlpt-word-list`의 `src/n2.csv`, `src/n1.csv` (MIT 라이선스, 원 출처 tanos.co.uk → jamsinclair/open-anki-jlpt-decks).
- 열: `expression,reading,meaning,tags`. N2 1,748개, N1 2,699개, 합계 4,447개. 레벨 간 중복 없음. 가나만 있는 단어 617개.
- 공식 JLPT 단어 목록은 2010년 이후 존재하지 않으므로 레벨 구분은 추정치다.

### 생성
1. `build_words.py`가 CSV를 받아 `source/`에 저장하고, N2 → N1 순서로 정리해 `words.base.json`을 쓴다. 같은 키가 또 나오면 처음 것(N2)만 남긴다.
2. 한국어 뜻은 Claude 세션에서 250개 단위 배치로 직접 생성해 `ko/NN.json`에 저장한다(API 키 불필요).
3. `build_words.py`를 다시 실행하면 `ko/*.json`을 합쳐 `docs/jlpt-vocab/words.json`을 쓴다. 뜻이 하나라도 빠지면 쓰지 않는다.

### 형식
```json
[{"k":"該当","r":"がいとう","ko":"해당(함)","en":"corresponding","lv":2}]
```
- 단어 키: `k + "|" + r`. 목록이 바뀌어도 진도가 유지된다.

### localStorage 키 (접두사 `jlpt-vocab:`)
- `progress`: `{ "該当|がいとう": [st, due, ivl, ease, lapses] }` — 평가마다 즉시 저장.
- `edits`: `{ "該当|がいとう": "고친 뜻" }` — `words.json` 업데이트와 분리.
- `settings`: `{ exam: "2026-12-06", buffer: 7, lastBackup: 일번호|null, today: 일번호|null, quotaToday: n, newDoneToday: n }`

### 백업 (`store.js`)
- 내보내기: `{ app: "jlpt-vocab", v: 1, progress, edits, settings }` JSON 파일. `navigator.share`(파일)로 iOS 공유 시트, 미지원 시 다운로드. 성공했을 때만 `lastBackup` 갱신.
- 가져오기: `fromBackup(text)`가 구조를 검증한다(app/v 일치, 세 키가 객체, progress 값은 길이 5 배열이고 st가 유효, exam이 `YYYY-MM-DD`). 실패하면 null → 기존 데이터 유지. 성공하면 확인 창 후 덮어쓴다.
- 홈 화면 PWA는 iOS 7일 저장소 삭제 대상이 아니지만, 앱 삭제 시 데이터가 사라지므로 백업 알림을 둔다.

## 오류 처리

- `localStorage` 쓰기 실패: 경고 창으로 백업 내보내기를 안내한다.
- `words.json` 로드 실패: 홈에 "인터넷에 연결해 한 번 열어 주세요" 표시.
- `progress`에 있지만 `words.json`에 없는 키: 큐에 넣지 않는다(삭제하지 않음).
- 가져오기 JSON이 깨졌거나 형식이 다르면 거부하고 기존 데이터를 유지한다.
