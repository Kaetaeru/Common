    운동모드 쓰는 법
    1. 타이머가 끝나 알람이 울리면 운동 시작을 눌러 운동모드로 들어갑니다. 운동한 시간이 올라가며 세트 수가 쌓입니다.
    2. 운동모드 종료 — 방금 세트를 마쳤다는 뜻. 같은 타이머가 바로 다시 시작합니다. 세트를 반복할 때 이 버튼만 누르면 됩니다.
    3. 세트 종료 — 이 운동을 끝냈다는 뜻. 타이머 선택창이 열리고, 다음 타이머를 고르면 바로 시작합니다.
    아이폰에서 앱처럼 쓰기
    1. 사파리로 이 페이지를 엽니다.
    2. 아래 공유 버튼 → 홈 화면에 추가를 누릅니다.
    3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다.
