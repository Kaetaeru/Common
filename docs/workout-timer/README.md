# 운동 타이머

개인용 운동 타이머. 운동은 손으로 끝내고 휴식만 재는 **세트** 방식과, 미리 정한 시간으로 자동 반복하는 **인터벌** 방식을 모두 담았습니다. 설치 없이 브라우저에서 열고, 아이폰에서는 홈 화면에 추가해 앱처럼 씁니다.

**주소:** https://kaetaeru.github.io/Common/workout-timer/

## 아이폰에서 앱처럼 쓰기

1. 사파리로 위 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 **비행기 모드에서도** 동작합니다.

## 기능

- **세트**(기본 탭): 운동 시간은 미리 정하지 않습니다. 운동하는 동안 시간이 올라가고, 직접 눌러 휴식으로 넘깁니다. 아래 *세트 탭* 참고.
- **인터벌**: 미리 정한 시간으로 자동 반복. 준비 → (운동 → 휴식) × 라운드 → 세트 휴식 → 다음 세트. 타바타처럼 운동 시간이 정해진 운동에 씁니다.
- **프리셋**(인터벌 탭): 타바타·HIIT·EMOM·근력 세트·복싱 3분·플랭크·스트레칭이 기본으로 들어 있고, 현재 설정을 이름 붙여 저장할 수 있습니다.
- **소리 안내**: 단계가 끝나기 3초 전부터 카운트다운 비프음, 전환 시 단계별로 다른 신호음.
- **스톱워치**: 랩 기록 포함.
- **화면 켜두기**: 운동 중 화면이 자동으로 꺼지지 않게 합니다(Screen Wake Lock 지원 기기).
- **백그라운드 알람**(기본 꺼짐): 켜면 화면을 잠그거나 다른 앱을 봐도 알람이 울리고, 잠금화면에 남은 시간과 재생·일시정지 버튼이 뜹니다.
- 설정·프리셋은 기기 안(localStorage)에만 저장됩니다. 서버로 보내는 데이터가 없습니다.

## 세트 탭

근력 운동처럼 **한 세트에 걸리는 시간이 매번 다른** 운동을 위한 흐름입니다. 재는 것은 휴식뿐입니다.

```
[운동 시작] → 운동 중(시간만 올라감) → [휴식 시작] → 휴식 카운트다운 → 알람
     ↑                                                                  │
     └──────────────────── [운동 시작] ←───────────────────────────────┘

                         [세트 끝] → 타이머 완전 종료
```

- **운동 시작**: 세트를 시작합니다. 운동하는 동안 시간이 올라가고, 언제 끝낼지는 직접 정합니다.
- **휴식 시작**: 방금 세트를 마쳤다는 뜻. 정해둔 휴식 시간이 내려가고, 끝나면 알람이 3.6초 간격으로 세 번 울립니다.
- 알람이 울린 뒤에는 **휴식 끝** 화면에서 시간이 계속 올라갑니다. 휴식을 얼마나 넘겼는지 보입니다.
- **세트 끝**: 타이머를 완전히 종료합니다. 몇 세트를 총 몇 분 동안 했는지 남습니다.
- 가운데 원을 누르면 지금 단계의 기본 동작이 실행됩니다(운동 중이면 휴식 시작, 그 외에는 운동 시작).
- 휴식 시간은 ± 버튼이나 30초·45초·1분·1분 30초·2분·3분 칩으로 바꿉니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 세트: 다음 단계로 | 가운데 원, 또는 **운동 시작** / **휴식 시작** |
| 세트: 완전 종료 | **세트 끝** |
| 인터벌: 시작 / 일시정지 | 가운데 원을 누르거나 **시작** 버튼 |
| 인터벌: 현재 단계 건너뛰기 | **건너뛰기** |
| 인터벌: 처음으로 되돌리기 | **처음으로** |
| 시간 조절 | ± 버튼, 칩, 또는 숫자를 눌러 직접 입력 |

## 알아둘 점

- 아이폰은 **측면 무음 스위치가 켜져 있으면 웹 소리가 나지 않습니다.** 소리 안내가 필요하면 무음을 해제하세요.
- **백그라운드 알람**은 들리지 않는 소리(최소 진폭 WAV)를 재생해 오디오 세션을 살려 두는 방식이라, 켜 두는 동안 **다른 앱의 음악이 끊깁니다.** 웹에서는 이 둘을 동시에 만족시킬 방법이 없습니다(화면이 꺼진 뒤에도 울리려면 오디오를 넘겨받아야 합니다).
  - 그래서 세트 탭은 **휴식이 도는 동안에만** 잡고, 알람이 다 울리고 9초 뒤에 놓습니다. 운동 중과 타이머를 끈 뒤에는 음악을 건드리지 않습니다. 음악은 보통 알람 뒤에 스스로 이어지지만, 앱에 따라 재생을 직접 눌러야 할 수 있습니다.
  - 옵션을 끄면 오디오 세션을 `ambient` 로 두어 **소리가 음악과 섞여서** 납니다. 대신 화면이 켜져 있는 동안에만 확실히 울립니다.
  - 인터벌 탭은 단계가 쉼 없이 이어지므로 도는 내내 잡습니다.
- 진동(`navigator.vibrate`)은 아이폰 사파리가 지원하지 않습니다. 안드로이드에서는 동작합니다.
- 타이머는 시계 기준 시각으로 계산하므로, 화면이 꺼졌다 켜져도 남은 시간이 밀리지 않습니다. 단계 전환음은 미리 예약해 두어 화면이 꺼진 동안에도 울립니다.

## 구조

정적 파일뿐이라 빌드 과정이 없습니다. 파일을 고치면 그대로 배포됩니다.

```
docs/workout-timer/
├── index.html            화면
├── style.css             스타일
├── app.js                타이머 로직
├── manifest.webmanifest  홈 화면 추가 정보
├── sw.js                 오프라인 캐시
└── icons/                앱 아이콘
```

내용을 수정한 뒤에는 `sw.js` 안의 `CACHE` 값(`workout-timer-v1`)의 숫자를 올려 주세요. 기기에 남은 예전 캐시를 지웁니다.
