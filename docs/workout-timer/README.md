# 운동 타이머

개인용 인터벌 타이머. 설치 없이 브라우저에서 열고, 아이폰에서는 홈 화면에 추가해 앱처럼 씁니다.

**주소:** https://kaetaeru.github.io/Common/workout-timer/

## 아이폰에서 앱처럼 쓰기

1. 사파리로 위 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 **비행기 모드에서도** 동작합니다.

## 기능

- **인터벌**: 준비 → (운동 → 휴식) × 라운드 → 세트 휴식 → 다음 세트. 한 화면에서 남은 시간, 라운드, 세트, 전체 경과/남은 시간을 봅니다.
- **프리셋**: 타바타·HIIT·EMOM·근력 세트·복싱 3분·플랭크·스트레칭이 기본으로 들어 있고, 현재 설정을 이름 붙여 저장할 수 있습니다.
- **소리 안내**: 단계가 끝나기 3초 전부터 카운트다운 비프음, 전환 시 단계별로 다른 신호음.
- **스톱워치**: 랩 기록 포함.
- **화면 켜두기**: 운동 중 화면이 자동으로 꺼지지 않게 합니다(Screen Wake Lock 지원 기기).
- **백그라운드 알람**(기본 꺼짐): 켜면 화면을 잠그거나 다른 앱을 봐도 알람이 울리고, 잠금화면에 남은 시간과 재생·일시정지 버튼이 뜹니다.
- 설정·프리셋은 기기 안(localStorage)에만 저장됩니다. 서버로 보내는 데이터가 없습니다.

## 운동모드

세트 사이 휴식을 재는 방식으로 쓸 때의 흐름입니다.

```
타이머 → (알람) → [운동 시작] → 운동모드 → [운동모드 종료] → 같은 타이머 다시 → …
                                        └→ [세트 종료]     → 타이머 선택창 → 고르면 바로 시작
```

- **운동 시작**: 타이머가 끝나 알람이 울리면 나타납니다. 누르면 운동한 시간이 올라가고 세트 수가 쌓입니다.
- **운동모드 종료**: 방금 세트를 마쳤다는 뜻. 같은 타이머가 바로 이어서 시작합니다.
- **세트 종료**: 이 운동을 끝냈다는 뜻. 타이머 선택창이 열리고, 고른 타이머가 바로 시작하며 세트 수는 0부터 다시 셉니다.

완료 알람은 놓치지 않도록 3.6초 간격으로 세 번 울립니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 시작 / 일시정지 | 가운데 원을 누르거나 **시작** 버튼 |
| 운동모드 들어가기 | 완료 화면에서 가운데 원 또는 **운동 시작** |
| 타이머 선택창 열기 | 완료 화면의 **타이머 선택**, 또는 운동모드의 **세트 종료** |
| 현재 단계 건너뛰기 | **건너뛰기** |
| 처음으로 되돌리기 | **처음으로** |
| 시간 조절 | ± 버튼, 또는 숫자를 눌러 직접 입력 |

## 알아둘 점

- 아이폰은 **측면 무음 스위치가 켜져 있으면 웹 소리가 나지 않습니다.** 소리 안내가 필요하면 무음을 해제하세요.
- **백그라운드 알람**은 타이머가 도는 동안 들리지 않는 소리(최소 진폭 WAV)를 계속 재생해 오디오 세션을 살려 두는 방식입니다. 그래서 **듣고 있던 음악이 끊길 수 있습니다.** 음악을 들으며 운동할 때는 꺼 두세요. 끄면 예전처럼 화면이 켜져 있는 동안에만 확실히 울립니다.
- 진동(`navigator.vibrate`)은 아이폰 사파리가 지원하지 않습니다. 안드로이드에서는 동작합니다.
- 타이머는 시계 기준 시각으로 계산하므로, 화면이 꺼졌다 켜져도 남은 시간이 밀리지 않습니다. 단계 전환음은 미리 예약해 두어 화면이 꺼진 동안에도 울립니다.

## 구조

정적 파일뿐이라 빌드 과정이 없습니다. 파일을 고치면 그대로 배포됩니다.

```
docs/workout-timer/
├── index.html            화면
├── style.css             스타일
├── app.js                타이머 로직
├── manifest.webmanifest  홈 화면 추가 정보
├── sw.js                 오프라인 캐시
└── icons/                앱 아이콘
```

내용을 수정한 뒤에는 `sw.js` 안의 `CACHE` 값(`workout-timer-v1`)의 숫자를 올려 주세요. 기기에 남은 예전 캐시를 지웁니다.
