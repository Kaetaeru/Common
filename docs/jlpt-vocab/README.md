# N1 단어

JLPT N2·N1 단어 4,447개를 간격 반복으로 외우는 개인용 단어장. 2026-12-06 N1 시험일에 맞춰 하루 신규 단어 수를 자동으로 정합니다. 아이폰 홈 화면에 추가해 앱처럼 씁니다.

**주소:** https://kaetaeru.github.io/Common/jlpt-vocab/

## 아이폰에서 앱처럼 쓰기

1. 사파리로 위 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행합니다. 한 번 연 뒤에는 오프라인에서도 동작합니다.

진도는 이 아이폰 안에만 저장됩니다. 홈 화면 아이콘을 지우면 진도도 지워지니 **설정·통계 → 백업 내보내기**로 가끔 파일을 저장해 두세요(백업한 적이 없거나 7일이 지나면 홈에 알림이 뜹니다).

진도는 홈 화면 아이콘으로 연 앱에만 저장됩니다. 사파리 탭에서 공부한 진도는 앱으로 옮겨지지 않으니 처음부터 홈 화면 아이콘으로 여세요.

## 쓰는 법

1. **학습**: 매일 [학습 시작]만 누르면 됩니다. 카드를 탭해 답을 보고 [모름]·[애매]·[앎]을 고릅니다. 모름은 5장 뒤에 다시 나옵니다. 뜻이 어색하면 ✎로 고칩니다.
2. **이미 아는 단어**: 처음 나온 카드에서 [이미 앎 — 학습에서 빼기]를 누르면 평가 없이 학습에서 빠집니다.
3. **훑어보기 (선택)**: 시간 날 때 단어만 보고 빠르게 거릅니다. 아는 단어는 [안다](또는 오른쪽 스와이프)로 빼고, 모르면 [모른다](왼쪽 스와이프), 답이 1초 보입니다. 많이 뺄수록 하루 분량이 줄어듭니다. 4,447개를 다 훑을 필요는 없습니다.

하루 신규 수는 `아직 안 배운 단어 ÷ (시험일까지 남은 날 − 7)`로 매일 다시 계산되고, 마지막 7일은 복습만 합니다. 훑어보지 않은 단어도 아직 안 배운 단어로 셉니다.

복습 간격은 최대 14일이라 시험 전 2주 안에 모든 단어를 한 번은 다시 봅니다.

## 단어 데이터

원본: [elzup/jlpt-word-list](https://github.com/elzup/jlpt-word-list) (MIT, 원 출처 tanos.co.uk). 공식 JLPT 단어 목록은 2010년 이후 없으므로 레벨 구분은 추정치입니다. 한국어 뜻은 Claude로 생성했습니다.

데이터를 다시 만들 때(저장소 루트에서):

```
python jlpt-vocab/build_words.py --offline
```

`jlpt-vocab/ko/*.json`의 뜻을 고친 뒤 실행하면 `docs/jlpt-vocab/words.json`을 다시 씁니다. 그다음 `sw.js`의 `CACHE` 값(`jlpt-vocab-v2`)의 숫자를 올려 주세요.

## 구조

```
docs/jlpt-vocab/
├── index.html            화면
├── style.css             스타일 (라이트/다크 자동)
├── app.js                화면 그리기와 이벤트
├── sched.js              복습 간격·하루 할당량 계산
├── store.js              저장과 백업
├── words.json            단어 데이터
├── manifest.webmanifest  홈 화면 추가 정보
├── sw.js                 오프라인 캐시
└── icons/                앱 아이콘
```

설계와 테스트는 저장소 루트의 `jlpt-vocab/`에 있습니다(`node jlpt-vocab/test.mjs`).
