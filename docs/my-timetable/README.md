# 내 시간표

APU AY2026 가을학기 내 수업 시간표. 열면 바로 **오늘 수업, 지금/다음 수업, 강의실**이 보이고, 다른 날과 주간 시간표도 찾아볼 수 있습니다. 아이폰 홈 화면에 추가하면 앱처럼 씁니다.

**주소:** https://kaetaeru.github.io/Common/my-timetable/

## 아이폰에서 앱처럼 쓰기

1. 사파리로 위 주소를 엽니다.
2. 아래 **공유** 버튼 → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행하면 주소창 없이 열리고, 한 번 연 뒤에는 오프라인에서도 동작합니다.

## 화면

- **하루**: 날짜별 수업 목록. 시간·교시·강의실·교수·실라버스 링크. 오늘이면 맨 위에 *수업 중(남은 시간)* 또는 *다음 수업(몇 분 후, 어느 강의실)* 이 뜹니다.
  - 위쪽 요일 줄을 누르거나, ‹ › 버튼, 좌우 스와이프로 날짜 이동. `다른 날짜 보기`로 아무 날이나 바로 이동.
  - 주말·겨울방학·시험 기간·보강일·공휴일 수업일은 학사력대로 안내합니다.
- **주간**: 월~금 × 교시 표. 칸을 누르면 그날로 이동.
- **과목**: 과목별 요일·교시·강의실·교수·실라버스.

시간은 모두 일본 시간 기준입니다.

## 데이터 고치기

수업·강의실·학사 일정은 전부 `data.js` 한 파일에 있습니다.

- 강의실이 바뀌면 해당 과목의 `room`을 고칩니다.
- 과목을 추가하면 `courses`에 과목을, `slots`에 `[요일, 교시, Class code]`를 넣습니다. `term`은 1쿼터만 `'Q1'`, 2쿼터만 `'Q2'`, 학기 내내 `'SEM'`.

고친 뒤에는 `sw.js`의 `CACHE` 값(`my-timetable-v1`)의 숫자를 올려 주세요.

출처: APU 공식 timetable `2023APS_Curriculum_26Fall_260928.xlsx`, AY2026 Academic Calendar.

## 구조

```
docs/my-timetable/
├── index.html            화면
├── style.css             스타일 (라이트/다크 자동)
├── data.js               과목·강의실·교시·학사력
├── app.js                날짜 계산과 화면 그리기
├── manifest.webmanifest  홈 화면 추가 정보
├── sw.js                 오프라인 캐시
└── icons/                앱 아이콘
```
