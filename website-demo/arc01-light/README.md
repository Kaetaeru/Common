# ARC 01 Light Room

`website-presentation/SHARED_PRODUCT_BRIEF.md`의 VELLUM / ARC 01 콘텐츠를 그대로 쓰는 단일 파일 제품 사이트 데모입니다.

사진 에셋이 한 장도 없습니다. 방, 램프, 그림자, 2700K 광원은 모두 `<canvas>`에서 매 프레임 계산됩니다.

## 데모가 증명하려는 것

- **실시간 라이팅** — 조광 10–100%에 따라 벽 워시, 바닥 풀, 의자·사이드 테이블의 캐스트 섀도(라이트맵에서 `destination-out`으로 깎아냄), 블룸이 함께 움직입니다.
- **실제 수치** — 좌면 조도는 광속 920 lm, 빔 입체각 1.6 sr, 거리 1.9 m의 역제곱 법칙으로 계산합니다. 소비전력은 12 W LED 기준으로 조광에 따라 변합니다.
- **스크롤이 시간을 움직임** — 스티키 스테이지에서 스크롤 진행도가 주광 앰비언트를 연속적으로 걷어냅니다. 클래스 스왑이 아니라 중간 프레임이 그대로 보입니다(`WORKING_RULES.md` 1–4항).
- **인터페이스가 제품 빛을 받음** — 램프 세기를 `--lit` CSS 변수로 내보내 헤드라인 글로우, 하이라인, 계측값 색이 함께 반응합니다.
- **`빛 켜보기`가 실제로 동작** — 브리프의 보조 액션이 장식이 아니라 광원 토글입니다.
- **Warm Silver / Graphite** 마감 전환이 캔버스 램프와 도면에 동시에 반영됩니다.

## 기술 메모

- 의존성 없음, 빌드 없음, 단일 HTML 파일. `index.html`을 브라우저로 열면 끝입니다.
- 렌더 패스: 방 알베도 → 가구 → 라이트맵 합성(`screen`) → 림 라이트 → 램프 → 비네트 + 그레인.
- `requestAnimationFrame`은 변화가 있을 때만 돌고, 값이 수렴하면 멈춥니다.
- 폰트: Hahmlet(한글 헤드라인) / IBM Plex Sans KR(본문) / IBM Plex Mono(계측값).
- `prefers-reduced-motion`에서는 밝기 보간과 트랜지션을 생략합니다.
- 400px 폭까지 세로 구성으로 재배치되며, 조광 슬라이더는 키보드로도 조작됩니다.

VELLUM과 ARC 01은 프레젠테이션용 가상 브랜드·제품입니다.
