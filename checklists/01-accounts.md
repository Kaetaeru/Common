# 01. 계정과 구독 준비

영상 시작 전에 가장 먼저 확인할 항목입니다.

## 체크리스트

- [ ] Google 계정이 있다
- [ ] Gemini Advanced를 사용할 수 있다
- [ ] Claude 계정이 있다
- [ ] Claude Pro 또는 Max를 사용할 수 있다
- [ ] GitHub 계정이 있다

## 영상에서 꼭 설명할 것

### Claude / Gemini는 API Key가 아니라 구독부터 확인
워크숍 기본 실습은 구독 모델 기준입니다.

- Claude Code CLI: Claude Pro 또는 Max
- Claude Desktop: Claude Pro 이상
- Antigravity CLI: Gemini Advanced
- Antigravity Desktop: Gemini Advanced

별도 API Key 발급은 기본 준비사항이 아닙니다.

### GitHub는 계정만 먼저 만들면 됨
이 단계에서는 Git이나 GitHub CLI 사용법을 몰라도 됩니다.

GitHub 계정이 없다면 먼저 회원가입만 완료합니다.

## 초보자에게 강조할 말

- “GitHub 계정”과 “Git 프로그램”은 다른 것입니다.
- 지금은 계정만 준비하면 됩니다.
- 로그인 연결은 프로그램 설치 후 진행합니다.
