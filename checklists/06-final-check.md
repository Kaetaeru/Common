# 06. 최종 검사와 문제 해결

영상의 마지막 단계입니다.

## 체크리스트

- [ ] 프로젝트 루트 폴더를 열었다
- [ ] `bun setup-common.ts`를 실행했다
- [ ] 필요한 항목이 모두 ✅로 표시된다
- [ ] 오류가 있다면 터미널 재시작 후 다시 확인했다
- [ ] 해결되지 않는 오류는 로그와 함께 운영자에게 전달할 준비가 되었다

## 최종 검사

프로젝트 루트 폴더에서 실행합니다.

```powershell
bun setup-common.ts
```

설치된 도구의 검증 결과가 표로 출력됩니다.

**필요한 항목이 모두 ✅라면 준비 완료입니다.**

## 자주 발생하는 문제

### `bun` 명령어를 찾을 수 없음

설치 직후라면 PowerShell 또는 Windows Terminal을 완전히 닫고 다시 실행합니다.

### `claude` 명령어를 찾을 수 없음

먼저 터미널을 다시 시작합니다. 계속 실패하면 설치 결과와 PATH 관련 문제를 운영자에게 전달합니다.

### `agy` 명령어를 찾을 수 없음

먼저 터미널을 다시 시작한 뒤 다시 확인합니다.

### PowerShell에서 스크립트 실행이 비활성화되었다고 나옴

설치 스크립트가 기본적으로 실행 정책을 조정하지만, 필요한 경우 다음 명령어를 사용할 수 있습니다.

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### 관리자 권한 없이 설치함

일부 `winget` 설치가 실패할 수 있으므로 관리자 권한 PowerShell에서 다시 진행합니다.

## 설치 로그

Windows 설치 로그 위치:

```text
%USERPROFILE%\workshop-setup-logs\
```

운영자에게 문의할 때 다음 두 가지를 같이 전달하면 좋습니다.

1. 오류 메시지가 보이는 화면 캡처
2. `workshop-setup-logs` 폴더의 관련 로그

## 영상에서 꼭 설명할 것

### “설치 완료”가 아니라 “검증 완료”가 종료 조건
설치 스크립트가 끝났다고 바로 영상을 종료하지 않습니다.

반드시:

```powershell
bun setup-common.ts
```

를 실행하고 결과를 보여줍니다.

### 오류가 나면 숨기지 않기
초보자용 영상이라면 대표적인 실패 상황에서 **터미널 재시작 → 다시 검사 → 그래도 안 되면 로그 전달** 흐름을 보여주는 것이 유용합니다.
