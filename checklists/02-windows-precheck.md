# 02. Windows 사전 확인

완전히 새 Windows PC를 기준으로 확인합니다.

## 체크리스트

- [ ] Windows 11을 사용 중이다
- [ ] 여유 디스크 공간이 5GB 이상이다
- [ ] 안정적인 인터넷 연결이 있다
- [ ] 관리자 권한을 사용할 수 있다

## 관리자 권한 여는 방법

1. Windows 시작 버튼을 누릅니다.
2. `PowerShell`을 검색합니다.
3. 검색 결과에서 PowerShell을 우클릭합니다.
4. **관리자 권한으로 실행**을 선택합니다.
5. UAC 창이 나오면 **예**를 누릅니다.

대안:

- `Win + X`
- **터미널(관리자)** 또는 **Windows PowerShell(관리자)** 선택

## 영상에서 꼭 설명할 것

### “관리자 권한”이 무엇인지 먼저 보여주기
초보자에게는 단순히 “관리자 PowerShell을 여세요”라고 말하지 말고 실제 클릭 경로를 보여주세요.

### 다운로드 용량
전체 설치 과정에서 약 1–2GB 정도를 내려받을 수 있으므로 안정적인 네트워크가 필요합니다.

### 이 단계에서는 명령어를 입력하지 않아도 됨
목표는 **PC가 설치를 진행할 수 있는 상태인지 확인하는 것**입니다.
