# 수업 녹음기

수업 시간에 PC에서 **녹음**을 누르고 끝나면 **정지**를 누르면, 내 시간표를 기준으로 이름을 붙여 과목별 폴더에 저장합니다.

```
문서\수업 녹음\네고시에이션 스킬\네고시에이션 스킬 2026-10-19 (5·6회차).mp3
```

## 실행

- **바탕화면의 `수업 녹음기.exe`** 를 더블클릭합니다. Python 없이 실행됩니다.
- 또는 저장소에서 `run_windows.bat` 더블클릭 (처음 한 번 sounddevice, soundfile, numpy 설치, Python 3 필요).

exe 를 다시 만들려면(코드를 고친 뒤): `python build_exe.py` → 바탕화면 exe 가 새로 바뀝니다.

### 시간표는 어디서 읽나

- 저장소 안에서 실행하면 `docs/my-timetable/data.js`.
- exe 는 켤 때마다 사이트(`kaetaeru.github.io/Common/my-timetable/data.js`)에서 최신 시간표를 받아 `%LOCALAPPDATA%\class-recorder\data.js`에 저장합니다. 인터넷이 없으면 마지막 저장본, 그것도 없으면 exe 를 만들 때 넣은 사본을 씁니다. 그래서 시간표를 고쳐 머지하면 exe 를 다시 만들 필요가 없습니다.

## 화면

- **지금 수업**: `지금 · 네고시에이션 스킬 · 1교시 · J103` / `다음 · 12:30 일본어 상급 · FⅡ230`
- **저장될 이름**: 녹음 전에 미리 보여 줍니다(30초마다 갱신). 정지할 때 실제 녹음한 시간대로 다시 계산합니다.
- **현재 음량**: 마이크 입력 크기 막대. 녹음 전에도 움직이니 마이크가 잡히는지 먼저 확인하세요. 소리가 너무 크면 빨갛게 됩니다.
- **마이크**: 기본은 Windows 기본 마이크.
- 저장 후에는 이름을 그 자리에서 고치거나 **폴더 열기**로 바로 열 수 있습니다.

## 이름 규칙

- 녹음 구간과 **20분 이상** 겹친 교시를 그 수업으로 봅니다. 몇 분 일찍 켜거나 늦게 꺼도 괜찮습니다.
- **회차는 교시마다 1회**(APU 실라버스 번호와 같음). 1·2교시를 이어서 녹음하면 `5·6회차`.
- 공휴일 수업일은 세고, 방학·시험·쿼터 사이·보강일은 세지 않습니다.
- 수업과 안 맞으면 `녹음 2026-10-19 14-30.mp3`로 `문서\수업 녹음\`에 저장합니다.
- 시간은 모두 일본 시간 기준입니다.

수업 정보는 `docs/my-timetable/data.js`를 그대로 읽습니다. 시간표를 고치면 녹음기도 따라갑니다.

## 알아둘 것

- 녹음 중에는 노트북이 잠자기 모드로 들어가지 않게 막습니다. 단, **덮개를 닫으면** Windows 설정에 따라 잠들 수 있습니다.
- 1분마다 파일에 저장하므로 프로그램이 갑자기 꺼져도 그때까지 녹음은 `문서\수업 녹음\녹음 중 ….mp3`로 남습니다.
- MP3 모노 약 56kbps, 100분에 약 42MB.
- 수업 녹음은 학교 방침과 교수 허락을 확인하세요.

## 구조

```
class-recorder/
├── app.py              창 (tkinter)
├── timetable.py        data.js 읽기, 정규 수업일, 회차, 이름 규칙
├── recorder.py         마이크 스트림, 음량, MP3 쓰기
├── test_timetable.py   timetable.py 테스트: python -m unittest test_timetable -v
├── run_windows.bat     더블클릭 실행 (Python 으로)
├── build_exe.py        exe 만들기 → 바탕화면에 복사
├── requirements.txt
├── 2026-10-19-design.md  설계
└── 2026-10-19-plan.md    구현 계획
```
