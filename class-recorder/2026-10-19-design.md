# 수업 녹음기 — 설계

날짜: 2026-10-19 · 상태: 승인된 설계 (구현 계획 전)

## 목적

수업 시간에 PC(Windows 노트북)에서 녹음 버튼을 누르면, 정지할 때 내 시간표를 기준으로
`네고시에이션 스킬 2026-10-19 (5·6회차).mp3` 같은 이름으로 과목별 폴더에 저장한다.

## 범위

- 녹음은 직접 시작/정지한다. 시간 맞춰 자동 녹음은 하지 않는다.
- 내 시간표 웹앱(`docs/my-timetable`)은 고치지 않는다. 그 앱의 `data.js`를 읽기만 한다.
- 받아쓰기, 클라우드 업로드, 설치형 exe는 범위 밖이다.

## 화면 (tkinter 창 하나)

위에서 아래로:

1. **지금 수업**: `지금 · 네고시에이션 스킬 · 1교시 · J103` 또는 `다음 · 10:35 일본어 상급 · FⅡ230` 또는 `오늘 수업 없음`.
2. **저장될 이름 미리보기**: `네고시에이션 스킬 2026-10-19 (5·6회차).mp3`. 녹음 전에는 "예상"으로 표시하고, 정지 후 실제 녹음 시간대로 다시 계산한다. 30초마다 갱신한다.
3. **음량 막대**: Windows 녹음기처럼 마이크 입력 크기를 실시간 막대로 보여 준다. 녹음 전에도 움직여서 마이크가 잡히는지 확인할 수 있다. 피크가 거의 최대이면 막대 끝이 빨갛게 된다.
4. **녹음 / 정지** 큰 버튼과 경과 시간(`00:42:13`).
5. **마이크 선택** 드롭다운. 기본값은 Windows 기본 입력 장치. 같은 장치가 여러 드라이버(MME/WASAPI 등)로 중복 표시되지 않게 기본 호스트 API 장치만 보여 준다.
6. 정지 후: 저장된 이름(그 자리에서 고쳐 이름 바꾸기 가능)과 **폴더 열기** 버튼.

## 이름 규칙

- 형식: `{과목 한국어 이름} {YYYY-MM-DD} ({회차}회차).mp3`. 과목 이름은 `data.js`의 `ko`.
- 연속 교시를 한 번에 녹음하면 회차를 `5·6회차`처럼 잇는다.
- 저장 위치: `문서\수업 녹음\{과목 한국어 이름}\`.
- 수업과 맞지 않으면 `녹음 2026-10-19 14-30.mp3`, 위치는 `문서\수업 녹음\`.
- 같은 이름이 이미 있으면 ` (2)`, ` (3)`을 붙인다.
- Windows 파일 이름에 못 쓰는 문자(`\/:*?"<>|`)는 지운다.

### 녹음 시간대 → 수업 맞추기 (정지할 때)

- 녹음한 날의 수업 교시마다 녹음 구간과 겹친 시간을 잰다.
- 20분 이상 겹친 교시만 인정한다. 일찍 켜거나 늦게 꺼도 같은 수업으로 잡힌다.
- 인정된 교시가 여러 과목이면 겹친 시간 합이 가장 큰 과목 하나를 고르고, 그 과목의 인정된 교시만 이름에 넣는다.
- 인정된 교시가 없으면 수업 외 이름을 쓴다.

### 미리보기 (녹음 전)

- 지금이 어떤 교시 안이거나 그 교시 시작 10분 전부터는, 그 교시와 바로 이어지는 같은 과목 교시를 묶어 이름을 만든다.
  - 예: 월요일 08:40 → `네고시에이션 스킬 … (5·6회차)`
- 그 밖의 시간에는 수업 외 이름을 보여 준다.

## 회차 계산

- APU 실라버스와 같이 **교시마다 1회**로 센다.
- 1쿼터 시작일부터 그날까지, 정규 수업일에 그 과목이 있던 교시를 모두 센다.
- 정규 수업일의 정의는 웹앱 `app.js`의 `dayInfo`와 같다:
  - 평일이고 1쿼터/2쿼터 수업 기간 안
  - 방학·시험·쿼터 사이·보강일은 제외
  - 공휴일 수업일(`holidaysWithClass`)은 포함
  - 과목의 `term`(Q1/Q2/SEM)에 맞는 쿼터에만 수업이 있다
- 보강일 수업은 시간표에 없으므로 세지 않는다.
- 시간은 모두 일본 시간(JST, UTC+9) 기준이다. PC 시계의 시간대 설정과 상관없이 JST로 계산한다.

## 구조

```
class-recorder/
├── 2026-10-19-design.md   이 문서
├── timetable.py           data.js 읽기, 정규 수업일, 회차, 이름 규칙 (화면·소리와 무관)
├── recorder.py            마이크 스트림, 음량 계산, MP3 쓰기
├── app.py                 tkinter 창 (위 둘을 묶는다)
├── test_timetable.py      timetable.py 테스트 (unittest)
├── requirements.txt       sounddevice, soundfile, numpy
├── run_windows.bat        더블클릭 실행. 처음 한 번 라이브러리 설치
└── README.md              사용법
```

### timetable.py

- `load(path)`: `docs/my-timetable/data.js`의 `window.TT = {...};` 객체를 읽는다. JS 객체 문법(주석, 따옴표 없는 키, 작은따옴표, 끝 쉼표)을 JSON으로 바꿔 `json.loads`한다. 경로는 저장소 기준 `../docs/my-timetable/data.js`.
- `slots_on(date)`: 그날 정규 수업 교시 목록.
- `session_number(code, date, period)`: 회차.
- `match(start, end)`: 녹음 구간 → (과목, 날짜, 교시들) 또는 None.
- `preview(now)`: 미리보기용 같은 결과.
- `file_name(result, start)`: 최종 파일 이름과 폴더.

### recorder.py

- 입력 스트림은 창이 열려 있는 동안 항상 열어 둔다. 콜백마다 피크를 계산해 음량 막대에 넘긴다.
- 녹음 중에는 같은 콜백에서 큐로 블록을 넘기고, 쓰기 스레드가 `soundfile`로 MP3에 쓴다.
- 설정: 모노, 48kHz(장치 기본값), MP3 고정 비트레이트 약 64kbps. 100분에 약 48MB.
- 1분마다 `flush()`한다. 프로그램이 비정상 종료돼도 그때까지 녹음은 읽을 수 있다.
- 녹음은 처음에 임시 이름(`녹음 중 … .mp3`)으로 쓰고, 정지 후 최종 이름으로 바꾼다.
- 녹음 중에는 Windows 잠자기 모드를 막는다(`SetThreadExecutionState`). 정지하면 푼다.

## 오류 처리

- 마이크가 없거나 열리지 않으면: 창에 안내를 띄우고 녹음 버튼을 끈다. 마이크 선택을 바꾸면 다시 시도한다.
- 녹음 중 마이크가 빠지면: 그때까지 녹음을 저장하고 알린다.
- `data.js`를 못 읽으면: 수업 외 이름(`녹음 날짜 시각`)으로라도 녹음은 되게 하고, 창에 경고를 띄운다.
- 최종 이름으로 바꾸기 실패(같은 이름 파일이 열려 있음 등): 임시 이름 그대로 두고 알린다. 녹음은 잃지 않는다.

## 테스트

`test_timetable.py`에서 실제 `data.js`로 다음을 확인한다.

- 회차
  - 2026-10-19(월) 네고시에이션 1·2교시 = 5·6회차
  - 2026-10-12(월, 스포츠의 날 수업일)도 센다: 3·4회차
  - 네고시에이션 1쿼터 전체 = 14회
- 2쿼터 첫 월요일(11/30)에 네고시에이션 없음
- 겨울방학 다음 첫 수업일(1/7 목) 회차가 방학을 건너뛰어 이어진다
- 겹침 맞추기
  - 08:40~12:20 → 네고시에이션 5·6회차
  - 08:50~10:20 → 5회차만
  - 14:30~15:00 → 수업 외
  - 12:20~12:40 → 겹침 20분 미만이라 수업 외
- 미리보기: 월 08:40 → 5·6회차
- 파일 이름: 금지 문자 제거, 중복 시 ` (2)`
- `data.js` 읽기: 과목 8개, 교시 6개

녹음과 화면(recorder.py, app.py)은 손으로 확인한다:
마이크 음량 막대, 10초 녹음 → 저장 → 재생, 녹음 중 강제 종료 후 파일 읽힘.
