# 수업 녹음기 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 수업 시간에 녹음하면 내 시간표 기준 `과목 날짜 (N회차).mp3`로 저장하는 Windows 프로그램.

**Architecture:** `timetable.py`(순수 로직: data.js 읽기, 정규 수업일, 회차, 겹침 맞추기, 이름)를 unittest로 먼저 만든다. `recorder.py`(sounddevice 입력 스트림 + soundfile MP3 쓰기 스레드)와 `app.py`(tkinter 창)는 그 위에 얹고 손으로 확인한다.

**Tech Stack:** Python 3.13, tkinter, sounddevice, soundfile 0.14 (libsndfile 1.2.2, MP3 지원), numpy.

**Spec:** `class-recorder/2026-10-19-design.md`

## Global Constraints

- 시간 계산은 모두 JST(UTC+9). PC 시간대와 무관.
- 회차는 교시마다 1회. 정규 수업일 규칙은 `docs/my-timetable/app.js`의 `dayInfo`와 같다.
- 겹침 인정 20분 이상, 미리보기는 교시 시작 10분 전부터.
- 파일 이름 `{ko} {YYYY-MM-DD} ({회차}회차).mp3`, 연속 교시는 `5·6회차`. 수업 외 `녹음 YYYY-MM-DD HH-MM.mp3`.
- 저장 위치 `~/Documents/수업 녹음/{ko}/`. 중복 시 ` (2)`. 금지 문자 `\/:*?"<>|` 제거.
- MP3 모노, 장치 기본 샘플레이트, `bitrate_mode='CONSTANT'`, `compression_level=0.9`(실측 약 56kbps).
- `docs/my-timetable` 파일은 고치지 않는다.
